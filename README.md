# Todo App

A lightweight, feature-rich vanilla JavaScript Todo application designed to work directly in any modern browser without requiring a server or build step, with persistence via LocalStorage.

## Features

- Add, complete, edit, and delete todos
- Filter todos by All, Active, or Completed
- Persistent storage using browser LocalStorage
- Item counter for remaining tasks
- Double-click to edit existing tasks

## How to Run

Simply open `index.html` in your web browser:
- Double-click `index.html` in your file explorer, or
- Drag and drop `index.html` into a browser window.

## Running Tests

This project includes unit tests for the core todo logic using Node.js's built-in test runner (`node --test`).

To run the tests:
```bash
npm test
```
